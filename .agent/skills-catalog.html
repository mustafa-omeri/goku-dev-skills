⚡ Özel Entegrasyon Rehberi: GitHub Reposu ve Harici API Ekleme (mock-asset-provider)

📁 1. Projeye Özel GitHub Görsel Paketi

Kullanıcı kendi Figma export paketini veya hazır görsel reposunu projeye bağlayabilir. Ajan tek komutla indirir ve public/mock-assets/ dizinine yerleştirir.

"github": { "enabled": true, "repo_url": "https://github.com/user/event-images-pack" }

🔑 2. Harici API Entegrasyonu (Unsplash & Pexels)

Kullanıcı kendi Unsplash veya Pexels API anahtarını .agent/config/assets.json içine ekleyerek yüksek çözünürlüklü tematik fotoğrafları doğrudan projeye akıtabilir.

"api": { "unsplash_access_key": "YOUR_UNSPLASH_KEY", "pexels_api_key": "YOUR_PEXELS_KEY" }

🌐 3. Sıfır-Ayar (Zero-Config) Otomatik Fallback

Hiçbir repo veya API anahtarı verilmezse ajan asla boş gri kutu bırakmaz; RandomUser (kadın/erkek portre), Picsum (etkinlik/manzara) ve DiceBear (SVG) servisleriyle besler.
